## Your Task

1. Read `current-task/feature.json` (including relatedSources) and `current-task/progress.txt`
2. Pick next step with `passes: false` and highest priority. Work only on that step.
3. Create implementation plan. In the plan add figma links if they are presented. Think about about technical implementation, UI/UX, edge cases, concerns, and tradeoffs. Dig into the hard parts I might not have considered.
4. In verification part of the plan add quality checks (e.g., typecheck, lint, test, test in the browser/curl)
